# Documentation

- Create documents only for a clear audience and purpose. Keep existing work items as the source of truth, following [Work planning](work-planning.md); avoid duplicate specifications.
- Create durable human handover or review docs when requested. Lead with outcomes; use examples or diagrams when they clarify the material.
- Keep writer planning notes and AI implementation notes in Git-ignored `tmp/`. Never commit or push them.
- Record enough verified context to resume the work. Keep notes concise and current; link to sources instead of copying them.
- Separate facts from assumptions and recheck stale notes against the source. A plan is not proof of implementation.
